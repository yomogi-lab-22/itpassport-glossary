# 📚 ITパスポート 3文字略語図鑑

ITパスポート試験の学習中に登場する、アルファベット3文字の略語をまとめた学習ツールです。

略語の意味だけでなく、英語の正式名称や分野、学習の優先度も確認できます。

覚えにくい略語を、検索と暗記チェックで繰り返し学習できるように制作しました。

## 🌐 アプリを開く

**[ITパスポート 3文字略語図鑑](https://yomogi-lab-22.github.io/itpassport-glossary/)**

ブラウザから無料で利用できます。

## ✨ 主な機能

- **略語一覧**：91語の略語・英語の正式名称・意味を収録
- **キーワード検索**：略語、英語、日本語の意味から検索
- **分野別表示**：ストラテジ系・マネジメント系・テクノロジ系で絞り込み
- **重要度表示**：学習の優先度を5段階の★で表示
- **暗記チェック**：略語から意味を思い出して答え合わせ
- **自己採点**：「正解」「不正解」「もう一度」で学習状況を記録
- **復習モード**：間違えた問題や、再確認したい問題だけを繰り返し出題

※重要度は公式の出題頻度ではなく、学習用の目安です。

## 💡 制作のきっかけ

ITパスポートの勉強を始めて、似たような英字略語が数多く登場することに気づきました。

一覧で意味を確認するだけでなく、覚えたかどうかを自分でチェックできるツールが欲しいと思い、制作しました。

学習の進み具合に合わせて出題分野を選べるようにしています。

## 🛠 使用技術

- HTML
- CSS
- JavaScript
- GitHub Pages

## 📝 補足

個人学習用に制作した非公式の学習ツールです。掲載用語や重要度は、公式の出題範囲・出題頻度を保証するものではありません。

学習記録は利用しているブラウザに保存され、異なる端末間では自動同期されません。
